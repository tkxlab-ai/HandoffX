### 2026-04-20 — 去 git 化（v0.5）
- **背景**：`/handoff-recall` 每次都执行 `git log` / `git status`，非 git 仓库会报 fatal；用户指出"handoff 是纯用户使用需求，不需要版本管理"。git hook 也是从 Beck/Grove "反射化触发"推导出来的假设，并非用户需求
- **选项**：
  - A：保留 git，只在非 git 仓库降级（if git_dir then ...）
  - B：彻底剥离——删除 hook、删除 git 采集、删除漂移检测；handoff 与版本管理正交
  - C：把 git 行为做成可选 flag
- **选择**：B
- **拒绝 A 的原因**：多一层条件分支，心智负担未消；且 handoff 的定位从来不是 commit 补充
- **拒绝 C 的原因**：flag 违背 YAGNI——用户已明确不要 git，不需要可配置
- **反悔代价**：低（删了还能从 git 历史恢复；但本项目未入 git，所以依赖本 Dev Log 记录）
