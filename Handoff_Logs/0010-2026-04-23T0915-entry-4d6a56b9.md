### 2026-04-23 09:15 — 修复 palette `/handoff` 四重重复：三源注册 → 单源 + 两 shim

**触发**: 用户截图显示 Claude Code palette 里 `/handoff` 出现 4 次。诊断发现 Claude Code 同时从三处登记 slash command：(1) `~/.claude/skills/*/SKILL.md` 的 `name:` 字段，(2) `~/.claude/commands/*.md`，(3) 任何嵌套在 skill 目录里的 `commands/` 子目录。旧版 `install.sh` 把 `handoff.md` shim 同时拷到 (2)，并把整个 `skills/handoff/commands/` 保留在 (3)，导致三源重复注册 `/handoff`。

**改动**:
- `install.sh:181` — `cp -r` 拷贝 skill 后立即 `rm -rf "$target_skills/handoff/commands"`，剥离源 (3)
- `install.sh:188-198` — shim 循环从"全拷 commands/*.md"改为"只拷 handoff-recall.md + handoff-tidy.md"；并主动 `rm` 旧版可能留下的 `handoff.md` shim
- `install.sh:202-206` — 安装验证只检查 recall/tidy 两个 shim 存在
- `tests/test_install.sh` — C1/C3/C6/C7/C10 全改为**负向断言**：`handoff.md` shim 必须不存在；断言 `handoff-recall.md` 存在
- 删除仓库根的遗留 `commands/` 目录（v0.4 时代的镜像，install.sh 从不读它；CONTRIBUTING.md 误把它当作 shim 正源）
- `CONTRIBUTING.md` / `README.md` / `INSTALL.md` / `HANDOFF.md` — 目录树与路径引用统一指向 `skills/handoff/commands/`（shim 源），并注明"/handoff 由 skill name 注册，无 shim"
- 清理本机运行态：`rm ~/.claude/commands/handoff.md` + `rm -rf ~/.claude/skills/handoff/commands/`
- 走过的弯路: 最初只想删 `~/.claude/commands/handoff.md` 一个；跑了一遍安装才发现 `skills/handoff/commands/` 子目录也被 Claude Code 当成第二源，必须在 install.sh 里主动剥离，否则每次重装都复活

**验证**:
- `bash tests/run_all.sh` → 6 suites, all passed；`test_install.sh` 26/26
- 本机 palette 应只剩一条 `/handoff`（来自 SKILL.md name）+ 一条 `/handoff-recall` + 一条 `/handoff-tidy`（用户需 `/reload-plugins` 或重启生效）
