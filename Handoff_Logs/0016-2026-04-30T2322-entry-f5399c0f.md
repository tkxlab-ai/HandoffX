### 2026-04-30 23:22 — SLA 安全 TDD 迭代：Codex 单源、readiness 硬校验、release 不可绕过、三平台去重

**触发**: 用户要求采用 superpowers + TDD，把审计发现拆成 3-5 分钟小任务循环开发；稳定性和安全性优先，完成后做三次回审，并再次确认 Claude Code / OpenCode / Codex 不再出现多重命令显示。

**改动**:
- `install.sh` — Codex 全局路径改为 `$HOME/.agents/skills`；项目级 Codex 也写 `.agents/skills`；新增 `cleanup_codex_legacy_mirrors` 清理旧 `.codex/skills/handoff*`
- `scripts/sync-codex-skills.sh` / `skills/handoff/scripts/sync-codex-skills.sh` — 从“镜像 `.agents` 到 `.codex`”改为“清理 legacy `.codex` 重复项”，保留 `.system` 和 custom-only skill
- `release.sh` / `INSTALL.md` — 移除 `FORCE=1` sanitizer 绕过与文档说明；敏感信息命中后 release 必须失败
- `scripts/handoff-lint.sh` / bundle 副本 — 新增 Development Log 外漂浮 `### YYYY-MM-DD` 条目检测，并允许 Decision Log 日期标题
- `scripts/tidy-handoff.sh` / bundle 副本 — 新增锚点不变量诊断（必须在 Development Log 内且仅一个）
- `skills/handoff/SKILL.md` / `references/handoff-write.md` / `references/handoff-tidy.md` / `references/handoff-init.md` / `commands/handoff-init.md` — 后置校验统一为 `validate-handoff.sh --readiness HANDOFF.md`
- `tests/test_install.sh` — Codex 全局/项目级均断言 `.agents/skills`，且不得生成 `.codex/skills/handoff*`
- `tests/test_sync_codex_skills.sh` / `test_doc_freshness.sh` / `test_release_dry_run_audit.sh` / `test_handoff_lint.sh` / `test_tidy_handoff.sh` — 增加对应 RED/GREEN 回归
- 走过的弯路: 初版 release FORCE 测试直接调用 `release.sh`，触发 `release.sh -> tests/run_all.sh -> test_release_dry_run_audit.sh -> release.sh` 递归；改为静态安全门测试，避免测试自身制造 P0 级循环
- 走过的弯路: 初版 floating-entry lint 把 Decision Log 的 `### YYYY-MM-DD` 决策标题误判成 Dev Log 漂浮条目；补 `Decision Log date headings are allowed` RED 测试后修复
