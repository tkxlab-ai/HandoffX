**Goal:** 把 `/handoffx` 写入流程里 AI 手工易错的步骤（取时间戳 / 重复检测 / 取号 / Current State 覆盖 / 指针再生）收进一个 bash CLI `scripts/hx.sh`，加凭证表头启发式、`--scan-home` 生态检查，并消掉老项目的两处噪音（`T2144` 日期、RECOMMENDED 逐条警告）。

**Architecture:** 新脚本 `scripts/hx.sh`（孪生到 `skills/handoffx/scripts/`）在 bash 里 source 既有 lib 并暴露六个子命令；`HANDOFFX.md` Current State 用 HTML 注释锚点分三块，`hx.sh block` 整块替换、tidy 幂等补锚点；`scan-credentials.sh` / `validate-handoff.sh` / `tidy-handoff.sh` / `handoffx-upgrade.sh` 各加一个独立函数；lib 的 `acquire_next_number` 取锁各步补显式检查。指令层（SKILL.md / write.md / 四 shim / 模板末尾注释）改为只调用 `hx.sh`。

**Tech Stack:** bash 3.2+（macOS）/ bash 5（Ubuntu 22.04，mawk）、awk/sed/grep POSIX 写法、既有测试框架 `tests/common.sh`（`assert_exit name expected actual` 精确比较、`assert_contains` / `assert_not_contains` / `assert_file_exists`、末尾 `summary` 在 FAIL>0 时返回非零）。

**Spec:** `docs/2026-11-02-v4-2-0-design.md`（v4：§1 ①–⑦、§2 约束、§4 裁定、§5 验收）。

**Status:** Task 1 完成（7becf14, 7e59f06）；Task 2 完成（8266aa7, 28c8deb, 2a53ec7）。本版从 Task 3 起生效。

## Global Constraints

- 脚本与测试零字面量：四件套新旧名只经 `scripts/lib/handoff-schema.sh` 常量（`$HX_MAIN_FILE` `$HX_LOGS_DIR` `$HX_DEC_DIR` `$HX_GOTCHAS_FILE` `$HX_LEGACY_*`）；旧 skill 名用 `_HXO=hand; _HXO="${_HXO}off"` 拼接；不得出现 `/Users/<name>/`、私有主机名、真凭证形态。
- `scripts/` 与 `skills/handoffx/scripts/`（含 `lib/`）byte-identical（`tests/test_scripts_sync.sh`）；每次改脚本后 `cp` 到孪生位置再提交。
- awk 内部正则不用 `{N}`（mawk）；非 ASCII 与字节类经 `-v` 从 `printf` 传入（`handoffx-upgrade.sh:195-197` 写法）；`printf | head` 禁用；临时文件 `mktemp` + rc 检查 + `mv` 原子写，目标是符号链接即拒绝。
- 门禁/遍历类代码：处理数 == 期望数（#33）；不可读 ≠ 干净（#24）；每个新门禁做「保留诊断 echo、只中性化失败判决」的变异证测试必红，记录后还原（#25）。失败注入优先用测试钩子（`HANDOFFX_TEST_*` / `HANDOFFX_*_FAIL_AT` 形态；无环境变量时零行为），不要靠「先 chmod 再建文件」这种非 root 下做不到的顺序。
- **计数同步（每任务）**：凡本任务新增/删除断言或套件，在同一提交内跑 `bash tests/test_doc_freshness.sh`，按 Test15/18/20 的期望值机械改 canonical 五文档 `README.md` `README_CN.md` `HANDOFFX.md` `CONTRIBUTING.md` `TEST-SCENARIOS.md`（`tests/test_doc_freshness.sh:33`）；新套件在 TEST-SCENARIOS.md 加一行。Test21 只查 CHANGELOG 当前版本段分隔符。

- 每任务：红测试 → 跑红（套件 exit 非零）→ 实现 → 跑绿 → 变异证 → 计数同步 → `bash tests/run_all.sh` 全绿 → 提交（首行英文、说 Why）。不推送、不打标签。中文沟通；代码注释英文。

## Review Focus

1. `hx.sh block set/get`：零锚点 → 2；半对、重复、顺序非法 → 4；`--from` 不存在**或存在但不可读** → 2；每种失败后目标文件 `cmp` 不变——Task 5。
2. `dup-check`：`date:` 缺失、epoch 非纯数字、日志目录存在但读不了 → exit 2 + stderr「无法判定」，绝不 stdout `ok`——Task 6。
3. `next-number`：lib 取锁任一步失败（锁文件打不开、`flock` 返回非零、mkdir 锁拿不到）→ stdout 为空、hx.sh 退出码 == lib 返回码（精确相等）——Task 4。
4. `--scan-home`：根读不了、任一阶段 rc 非零（stderr 为空也算）、枚举数 ≠ 扫描数、悬空链接 → exit 2 +「扫描不完整」；0 个根 → ℹ️ 且无 ✅——Task 8。
5. tidy 日期规整：两个候选一成一败 → exit 1、失败文件原样、成功文件已改、汇总 `候选 2 / 成功 1 / 失败 1`；`T21:44` / `T214` / Decision 日期零改动；二次运行零改动——Task 7。
